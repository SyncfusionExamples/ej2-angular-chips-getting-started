# NgChip

## Repository Description

NgChip is an Angular component library project built with Angular CLI that provides reusable chip/tag UI components for Angular applications. This project demonstrates modern Angular development practices with proper build configuration and development workflows.

## Project Overview

NgChip is a specialized Angular component library designed to provide developers with flexible, accessible, and customizable chip and tag components. The project was generated using Angular CLI version 7.1.3 and includes a complete development and build pipeline for creating production-ready Angular components.

## Features

- Pre-built, reusable chip and tag components
- Built with Angular CLI for optimal compilation and bundling
- Complete development and production build configurations
- Hot module reloading for rapid development
- TypeScript support for type-safe component development
- Production-ready build artifacts

## Prerequisites

Before you begin, ensure you have the following installed on your system:
- Node.js (compatible with Angular CLI v7.1.3)
- npm (Node Package Manager)
- Angular CLI v7.1.3 or higher
- A code editor (Visual Studio Code recommended)

## Installation and Setup

1. Clone or download the repository
2. Navigate to the project directory
3. Run the following command to install all dependencies:

```bash
npm install
```

## Development Server

To start the development server and preview the components:

```bash
ng serve
```

Navigate to `http://localhost:4200/`. The application will automatically reload whenever you modify any of the source files. This enables rapid development and testing of component changes.

## Build

To build the project for production:

```bash
ng build
```

The compiled build artifacts will be stored in the `dist/` directory. For optimized production builds with minification and optimization flags enabled, use:

```bash
ng build --prod
```

## Usage

Use the chip components in your Angular templates by importing the component module and adding the component selectors to your templates. Refer to the component documentation for detailed usage examples and configuration options.
